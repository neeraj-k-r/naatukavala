# ATS-Friendly Resume Template

Single-column, plain-text resume that parses cleanly in Applicant Tracking Systems.
Copy the variant you need into Word or Google Docs, fill it in, then export as PDF.

**File name:** `Firstname-Lastname-JobTitle-2026.pdf`

---

## Formatting rules (ATS resume format 2026)

| Rule | Value |
| --- | --- |
| File format | PDF (DOCX accepted) |
| Font | Arial, Calibri, Cambria, Times New Roman or Helvetica |
| Size | 10–12 pt body, 12–14 pt headings, 16–20 pt name |
| Layout | One column, left aligned |
| Margins | 0.5–1 inch, all sides |
| Sections | Standard headings only (Summary, Skills, Experience, Education) |
| Bullets | 1–2 lines, action verb + result + number |
| Length | 1 page (fresher), up to 2 pages (7–10+ years) |

**Never use:** photos, icons, graphics, tables, text boxes, multi-column layouts,
coloured sidebars, headers/footers, skill bars, keyword stuffing, unusual fonts.

## Bullet formula

**Action + What + Result + Number/Tool**

Good: `Automated inventory reports in Excel, saving 6 hours per week.`
Bad: `Responsible for making reports.`

Action verbs: Led, Built, Designed, Launched, Automated, Improved, Reduced,
Increased, Optimised, Migrated, Coordinated, Delivered, Streamlined.

---

## Keyword targeting

1. Collect 3–5 similar job descriptions and note the skills/tools repeated.
2. Put high-priority skills in **Skills** and repeat them inside **Experience bullets**.
3. Put certifications in **Certifications**, tools inside bullets with outcomes.
4. Use natural sentences — no comma-soup blocks, no invisible/keyword-stuffed text.
5. Add synonyms the JD uses (Excel / MS Excel, Salesforce / SFDC).

## Pre-upload checklist

- [ ] Single column, left aligned, no tables or text boxes
- [ ] No photos, icons, graphics, charts or skill bars
- [ ] Standard section headings (Summary, Skills, Experience, Education)
- [ ] Arial/Calibri/Helvetica 10–12 pt
- [ ] Every bullet starts with an action verb and has a number or metric
- [ ] Keywords from the job description appear naturally
- [ ] Dates consistent: `Jan 2022 - Present`
- [ ] No spelling/grammar errors; same tense per role
- [ ] 1 page (fresher) / max 2 pages (experienced)
- [ ] Saved as PDF: `Firstname-Lastname-JobTitle-2026.pdf`
- [ ] Contact info is plain text (no header/footer, no image)
